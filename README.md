# 白内障執刀ノート

白内障手術動画を見返しながら、CCCの開始・終了時刻と反省点を記録するFlutterアプリです。

## MVP範囲

- 症例の新規作成
- 症例一覧
- 症例詳細
- 動画選択
- 動画再生、一時停止、シーク
- 1秒/5秒単位の前後移動
- 再生速度変更
- CCC開始位置、終了位置の登録
- CCC所要時間の自動計算
- CCC自己評価
- CCC反省点
- CCC開始位置へのジャンプ
- アプリ再起動後のローカル永続化
- 選択動画のアプリ専用領域へのコピー

## データ保存

ローカル永続化にはDriftを使用しています。UIはDriftを直接呼ばず、Repositoryを経由してデータを読み書きします。

選択された動画はApplication Supportディレクトリ配下へコピーして管理します。元動画は変更・移動・削除しません。DBにはアプリ内コピーの相対パスと表示用の元ファイル名を保存します。

保存構造:

```text
<ApplicationSupportDirectory>/
  videos/
    <surgeryRecordId>/
      <uuid>.<mp4|mov|m4v>
```

既存バージョンで保存された外部絶対パスは互換処理で外部参照として扱います。ファイルが存在する場合は、次回動画を開く際にアプリ内コピーへ移行します。存在しない場合は動画の再選択が必要です。

## プライバシー

患者氏名、患者ID、生年月日の入力欄はありません。動画や記録内容を外部送信する機能もありません。
